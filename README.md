# AI 카카오톡 2D SD 이모티콘 스튜디오 (Android Standalone v3.1)

외부 서버(Cloud Run 등) 의존성 없이 **안드로이드 스마트폰 자체에서 100% 독립 실행**되는 AI 카카오톡 2D SD 이모티콘(15종) 생성 앱입니다.

## 주요 기능
1. **Gemini API 키 자체 설정 (`MainActivity.java`)**: 앱 최상단 카드에서 Google AI Studio(`aistudio.google.com/apikey`)의 Gemini API 키(`AIza...`)를 입력·저장(`SharedPreferences`)하고 연결 테스트를 수행합니다.
2. **인물 사진 업로드 & 카메라 촬영**: 앨범 선택(`ACTION_GET_CONTENT`) 및 카메라 촬영(`MediaStore.ACTION_IMAGE_CAPTURE`) 지원.
3. **10종 분위기 & 3가지 상황 테마**:
   - 기본 8종 분위기(`귀엽게`, `발랄하게`, `진지하게`, `코믹/익살스럽게`, `직장인 공감`, `따뜻하고 감성적으로`, `애교 가득 러블리`, `힙 & 트렌디하게`) + **`🎣 낚시 테마`** + **`✈️ 여행 테마`**
   - 낚시 테마 6대 대상 어종(`광어`, `참돔`, `돌돔`, `갈치`, `문어`, `부리`) 선택 및 대물 인증샷 포즈 지원.
4. **5개 국어 자동 전환 & 15종 문구·포즈 개별 편집**:
   - `한국어`, `English`, `日本語`, `中文`, `Español` 지원.
   - 15개 슬롯 각각의 **출력 글자**와 **포즈/행동 프롬프트**를 모두 직접 편집 가능 (`1열 넓게 편집` / `크게 편집` 모달 / 실시간 전체 프롬프트 자동 반영).
5. **100% 기기 내(On-Device) 이미지 처리 (`OnDeviceStickerEngine.java`)**:
   - 인물 중앙 크롭 → 흰색 배경 분리 → 3×5 이모티콘 시트 생성 → 흰색 여백 코리더 감지 15등분 자동 슬라이싱 → 4방향 BFS Flood-Fill 외곽 배경 투명화(`PNG`) → `ZIP` 번들 생성 및 `Downloads/KakaoStickers` 저장 → 17개 파일 일괄 공유/이메일 발송.

## 빌드 방법

```bash
./build_apk.sh
```
